# N05-01 reference geometry and notices

The served GLBs in `apps/mission-control-web/assets/anatomy/` are adapted from **BodyParts3D / Anatomography4.3, objects set4.3, FMA3.0**. These are generic adult male reference assets, not scans of ASTRA crew, complete anatomy, clinical models or a physiological simulation. No source anatomy was generated.

**Credit:** BodyParts3D, ©2008 The Database Center for Life Science, licensed under CC Attribution-Share Alike2.1 Japan. DBCLS's original information page credits model generation to Kaori Fujieda and Shio Imai, concept mapping to Nobutaka Mitsuhashi/Isamu Muto/Kousaku Okubo and project design to Kousaku Okubo. Per-file original creator strings are preserved without assigning unverified individual authorship.

Original source: https://lifesciencedb.jp/bp3d/ . Release manifest from its public `get-info.cgi?version=4.3&cmd=concept-objfiles-list`; component catalogue through the public upload-all-list form. Original subset geometry comes only from the viewer's supported `download.cgi` custom-download flow, using an anonymous in-memory session. No mirror, credentials, full atlas or personal browser profile.

The original-site notice, preserved in `bodyparts3d-4.3/source/official-license.html`, explicitly specifies [CC BY-SA2.1 Japan](https://creativecommons.org/licenses/by-sa/2.1/jp/). Retain attribution, this license URI and the same license for redistributed/adapted anatomy. Changes: uniform coordinate conversion, per-element vertex clustering, rebuilt normals, grouping and GLB packaging; display colors/lights are illustrative. No endorsement is implied. Software remains separately licensed; Three.js0.186.1 is MIT, with its complete notice in `apps/mission-control-web/vendor/three/LICENSE`.

**Notice distinction:** the separate LSDB archive4.0 release currently declares [CC BY4.0](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html), updated2025-02-27. Its English README still contains an older BY-SA2.1 summary hyperlink. That4.0 grant is not asserted for the original-site4.3 subset. Both official notice snapshots are retained. The4.0 candidate was rejected for this task because its supplied lung compounds contain branching internals but no lung-parenchyma surface concepts. No4.0 geometry was imported.

`bodyparts3d-4.3/inputs.json` records326 originals (304 bones,three chamber-wall surfaces,18 pulmonary-parenchyma segments andone skin surface), raw SHA256/bytes, catalogue FMA/BP/FJ and author/filename strings, original exported header identities, release and metadata hashes. All original FJ/concept/compatibility IDs match the selected4.3 set.142 BP representation IDs differ between catalogue lookup and exported headers; both observed IDs are retained. Whole-heart compound membership is incomplete, so the preview explicitly selects three named wall concepts rather than claiming the complete source compound.

Raw coordinate units are explicitly millimetres in OBJ `Bounds(mm)` headers. All components use the same transform, `[ (x-cx)/1000, (z-floor)/1000, -(y-cy)/1000 ]`, into metres/Y-up. Parameters, original body dimensions, derived bounds/counts, membership/index ranges, simplified-asset hashes and pipeline limitations are recorded in the served manifest. No per-organ shift/scale, replacement surfaces or speculative registration.

The source's official information/release notices warn of unrepresented concepts, incorrect models and possible concept assignment errors. ASTRA verifies provenance/membership and visually checks reference alignment; it does not certify anatomical accuracy. [Completion and exact tests](../../docs/N05_01_COMPLETION.md).
