# N14 offline retrieval engineering contract v1

Official module: **Semantic retrieval and support validation**, also described as Offline Research Evidence Retrieval. Official families R21/R41–R43/R59; AC11–14 remain transitive acceptance criteria, not waived. This additive contract consolidates existing N14-01–05 behavior. Old policies, indices, vectors, claims and review records are immutable inputs.

Engineering audit clauses: (1) fixed N13consumer/hash/instance; (2) exact index reconstruction and vector validity; (3) lexical baseline; (4) semantic provider/input/numeric contract; (5) two frozen hybrids; (6) source/citation/role/scope checking; (7) bounded authorized offline service; (8) seen evaluation and denominator integrity; (9) prospective review/promotion gate; (10) durable result/cold verification; (11) inactive N15/N16compatibility; (12) actual E2E/security/QA/resources. These are audit subdivisions of official requirements, not invented module IDs.

Trusted local launcher creates process-local researcher/demo_admin capability, immutable source scope and explicit experimental permission. JSON role/scope/model/corpus paths cannot grant access. All authorized evidence is public retained research; no private cognition or crew data is consumed. Requests: schema astra.n14.search.v1, query1–1200characters, top_k1–5, fixed policy ID, optional excluded canonical sources and fixed corpus hash. Rich lexical uses unchanged tokenization/stop list,3topic/1content/minimum3, stable window-ID ties and best-window unit dedup. Semantic uses exact384finite normalized query embedding; saved document vectors encode original text only. Hybrids use full frozen top5 inputs then truncate to requested k: fixed2:1RRF/60 or append-only prefix. Exclusions filter before ranking. Similarity is not confidence, relevance, entailment or clinical support.

Absent native provider returns explicit lexical fallback with requested/effective policy and MODEL_UNAVAILABLE. Malformed/corrupt vector or provider failure fails closed; no silent fallback. Native provider installation/loading is gated separately by the actual resource contract. Test injection exercises orchestration only, not model qualification. Timeout/cancellation discards late results; cooperative process JS cannot forcibly interrupt arbitrary native I/O. No networking or executable tools are owned by this service. Local code is a trusted integration boundary, not an OS sandbox against malicious installed code.

Output astra.n14.search-result.v1 includes corpus/index/policy/source versions, canonical quotation/citation/scope, score with meaning, data review status, requested/effective method, fallback, support UNKNOWN/factual answer null. Attribution uses unchanged N14-02checker. No arbitrary paraphrase or numerical entailment claim. N15 receives evidence only; N16descriptor stays inactive. No HTTP/application UI integration under current exception.

New durable receipts: bounded task/OS-temp output roots, fixed filenames, no symlinks/hardlinks, exclusive staged writes, fsync/rename/parent ACK/commit receipt/readback; hash-bound request/result and canonical snapshot. Recovery checks original inputs and recomputes deterministic ranking from committed input (including saved query vector only for QA/provider results), never loads a model. This is explicit ranking verification, **not zero ranking computation**. Identical requests reuse an immutable content-addressed receipt. Failed acknowledgement/incomplete stages are visible and never PASS. Max16receipts/root,2MiB/receipt, query deadline1000ms(default),5000msmax; no absolute RSS/disk guarantee. Original sources never copied. No reconstruction of missing models.

All40remain seen_development; historical24/16membership is not independent. Saved semantic lists are archival replay, not fresh query inference. Shared positive evidence cannot cross a claimed disjoint split. Claims without v2bindings are NOT_ASSESSED. New prospective cohorts require existing independent review protocol; schema validity never authenticates reviewers or authorizes execution/promotion. Baseline retained irrespective of candidate development metrics.

External gates: current native resource approval; independent identical-graph numerical reference; actual prospective questions/review/owner execution authorization; full N13/N07, source/rights/science/hardware/release approvals. Engineering tests cannot supply any of these.
