1 · Executive overview
ASTRA explores how a crew and remote support team could inspect health information when connectivity
is limited or delayed. The implemented prototype unifies synthetic observations, deterministic monitoring,
durable records, 3D navigation, waveform replay and separated research tools. Its research value is the
inspectable engineering workflow—not proof of clinical effectiveness.

3 · The verified technology stack
The main application deliberately uses a small local stack. A framework is a package that supplies
application structure; ASTRA’s main interface does not use React, Next.js or Express. Algorithms and
charts are mostly repository code rather than large scientific libraries.
Technology
What / why / actual use

Main implementation language; explicit import/export boundaries across browser,
HTTP services and algorithms. package.json sets type: module. No TypeScript
build is required.
Node.js 24.21.0–24.x / npm
Runs the server, scripts and node:test. npm start invokes the server file directly;
npm dev uses Node’s watch mode. Root engine excludes Node 25+.
Native node:http / node:crypto
HTTP routing/static files/SSE and cryptographic hashes, random session tokens
and timing-safe service-token comparison. No Express dependency.
SQLite / node:sqlite DatabaseSync
Embedded durable local database; no separate database server or cloud

worker shell cache and responsive styling.
Three.js 0.186.1 / WebGL2
Pinned 3D library, GLTFLoader and controls; local anatomy assets rendered by

Local SVG / Canvas code
Charts and visual components live in ui.mjs/scenes.mjs; no Chart.js or D3

5 · SQLite: memory that survives restart
SQLite is a database engine inside the application process. It stores structured records in a local file. This
suits an offline prototype because startup does not require a remote account, network connection or
separate database server. It does not by itself provide medical certification, encryption or high-availability
mission infrastructure.
ASTRA_DB
 selects the file. The CLI defaults to 
data/runtime/astra.sqlite
; the presentation flow creates a
new temporary directory instead. The library’s in-memory default is used by isolated tests, not the
ordinary CLI persistence path. Rows often combine indexed IDs/times with a JSON field; waveform
chunks store signal bytes as BLOBs.

Atomicity, idempotency and cold recovery
transaction()
 uses BEGIN IMMEDIATE and commit/rollback, so related writes succeed together or fail
together. Event IDs and request IDs stop duplicate commitments. WAL mode, foreign-key checks and a
busy timeout support durable local work. Many history tables have append-only triggers; mutable state is
not universally immutable. Additive schema setup preserves old evidence. A cold restart reconstructs
committed state; replaying a result is not permission to rerun a model or worker.

6 · Is the health data real or fake?
“Synthetic” means intentionally generated rather than measured from a person. It is not the same as
hardcoding a decorative number. ASTRA’s simulator commits time-stamped observations through real
services, drives monitoring rules and supports repeatable replay. That demonstrates software behavior; it
does not demonstrate physiology or clinical predictive accuracy.
Data type
What the current repository establishes
Hardcoded display-only values
A fake fixed number would not exercise source/crew/time validation. The accepted
monitoring/anatomy workflow reads actual application-generated observations
instead.
Deterministic synthetic telemetry
The main six-crew demo uses seeded generation, individual reference
distributions, scenario effects, source times and quality states. No physical sensor
is needed.
Imported synthetic waveforms
The app accepts its bounded synthetic ASTRAWV1/CSV contract, including
authored gaps. These are not authentic live ECG/PPG recordings.
Authentic publications / metadata
Two N13 NASA PDFs plus N07 NASA/OSD metadata are retained research
sources. A paper is evidence text, not a live biometric feed.
Authentic BIDMC numerics
One small de-identified PhysioNet numerics CSV is in the approved local archive.
It is not the app’s crew feed, not a raw waveform import and not sufficient
independent clinical validation.
Sleep-EDF and other desired
datasets
The required accepted Sleep-EDF pair is unavailable; a partial acquisition is not a
qualified source. PTT, RadLab and other named source requirements remain
open.
Actual astronaut wearable data
Not verified from current repository. The current demo is not connected to
astronaut devices or a medically validated live wearable.
What can honestly be claimed?
ASTRA can demonstrate persistent synthetic monitoring, quality-aware visualization, isolated crew data,
deterministic scenario replay and offline attribution. It cannot establish actual disease sensitivity,
treatment effectiveness, real sensor calibration or general predictive reliability.
What would a future sensor require?
A producer interface exists for authorized scalar telemetry, but a real deployment would need an actual
device adapter, calibrated units/cadence, authenticated provenance, clock synchronization, missingness
handling, privacy and source rights, clinical evaluation and new operational approval. A working POST
route is only one small part of that work.
Documentation conflict:
 an older root README statement that no physiological dataset was
downloaded is stale relative to the BIDMC numerics inventory. The dataset card identifies a real
7,644-byte public research file; it does not authorize feeding patient records into this demo.

7 · N01: security and privacy
Security has several separate jobs. Authentication identifies a session; authorization limits its actions;
integrity checks detect altered records; privacy restricts who can see sensitive information. A local
research prototype can implement these controls without being a production medical identity system.
Session mechanics
The demo role picker creates a session with a random 32-byte token. The database stores its SHA-256
hash, not the raw token. The browser receives an HttpOnly, SameSite=Strict cookie with a two-hour
maximum lifetime. Server-side expiry is checked on later requests. Logout invalidates the session.
Loopback binding limits ordinary access to the laptop; it does not make all local files or browser activity
safe automatically.
Control
Implementation and consequence
Role permissions
contracts.mjs defines allowlisted actions. A researcher cannot acknowledge an alert
just because research access exists. System administrator does not automatically
have health-read scope.
Crew scope
An astronaut session is bound to CREW-03. crew authorization rejects another crew
ID; changing the URL does not expand access.
Private cognition
N10 checks actor/device, current consent and review-sharing eligibility. Demo
administrator is not a universal private-data bypass.
Source / input validation
Queries, regions, channels, metric IDs and request bodies are bounded and
validated. An untrusted mesh label cannot become arbitrary SQL or a file path.
Audit integrity
Audit entries include previous/current hashes. Append-only triggers protect selected
history tables. A hash detects changed bytes; it is not encryption or a human
scientific signature.
External scalar ingest
An optional timing-safe service-token check protects this producer path; if the
configured token is absent, ingestion is disabled.
Safe request example
GET /v1/crew/CREW-03/anatomy?region=cardiovascular
Cookie: [existing session cookie; deliberately not printed]
Astronaut assigned CREW-03 → permitted eligible read
Same session requesting CREW-01 → 403 Forbidden
Expired / missing session → 401 Unauthorized
The cookie placeholder above is explanatory, not a credential to copy. The demo login proves
engineering role behavior, not password-based identity assurance. Database-at-rest encryption, deployed
TLS, real organization identity integration and regulatory certification are not established by the current
loopback setup.

8 · N02: how monitoring really works
The active monitoring decision is 
deterministic code
: the same eligible observations and detector state
produce the same decision. It is not a Qwen judgment. Personal reference values and source-time
persistence help distinguish a sustained authored change from a single value.
Observation → validate source, crew, range, quality and time
Eligible resting signal → robust standardized deviation
Maintain source-time persistence → evaluate fixed Tier A rules
Persist qualified event → build template case → human acknowledgement
Queue report → transmission → delayed Earth receipt
Figure T4. Current display state and persisted event history are different outputs.
Personal deviation and quality gates
The reference center is a median. The scale is the larger of a metric floor and 1.4826 × median absolute
deviation (MAD). The detector computes 
z=(value−center)/scale
. For illustration only, center 68, scale
4.5 and value 86 gives z=4. This is a software-relative deviation, not a claim that 86 bpm is medically
dangerous.
Current rule parameter
Repository value / engineering meaning
Quality / freshness
Minimum confidence 0.7; fresh metric time bounded by max(5,000 ms,
3,000/sampling_hz). Poor data yields Gray.
Amber multi-signal / single-signal
At least two |z|≥2 signals for 90 s, or one |z|≥4 for 120 s.
Rapid change
≥3 robust standardized units/minute sustained for 60 s within its rate
window.
Red escalation
Two severe |z|≥4 signals for 180 s, or one |z|≥6 signal for 180 s, subject
to eligibility/persistence logic.
Only new monotonic source observations advance persistence; holding a sample does not. Source
changes reset relevant state. HR/HRV/respiration are excluded from resting-rule interpretation during
activity. A missing or suspect signal cannot be silently counted as healthy. The displayed heuristic
evidence score is not a validated probability.
Acknowledgement is not resolution or receipt
The engine records an authorized human actor/time and queues a stable case-report ID atomically.
Pending case preparation can return a conflict. Communications preserves queue and receipt state
across restart. Defaults include a 720,000 ms one-way delay and 128 kbps link; blackout/retry can delay
further. N06 only reads these records—it does not create or acknowledge them.

9 · N03/N04: the browser application
The interface is an application made from HTML, CSS and JavaScript modules. N03 supplies
correctness, routing/state behavior and performance engineering; N04 supplies the accepted cinematic
navy/electric-blue visual language. A modern appearance is separate from scientific approval.
State and communication
app.mjs
 keeps the current identity, selected page, crew, view and latest mission snapshot. A shared fetch
wrapper sends JSON requests to the same local origin. Server-Sent Events (EventSource) deliver
mission updates through the mission stream. This is one-way server push; user actions still use explicit
HTTP requests.
Request gates cancel obsolete reads. Session version checks also prevent late replies from updating a
new session. Page changes and unmounts dispose components; page suspension aborts session-wide
work and stops polling, then a compatible resume refreshes source state. Compatible selection is
preserved separately from health records.

Figure T5. Network, persistence and view state have different purposes. Solid: implemented in the stated scope. Dashed: inactive or

Reliability and accessibility
The frontend distinguishes loading, empty, denied, failed and stale states. A named service-availability
region announces degradation without turning UNKNOWN into Green. Keyboard controls, visible focus,
responsive tables, reduced motion and 200% zoom support alternate ways of using the system. Local
cached synthetic snapshots are not a live backend connection; private case content is excluded from that
fallback snapshot.
Why a fast API can coexist with a slow crew switch
An API may return small JSON in milliseconds while the browser still loads, verifies, decodes and uploads
large geometry, initializes graphics and remounts a scene. Retained final acceptance measured an API
p95 near 14.7 ms but crew switching including 3D remount around 8.2–8.9 s. These measure different
work. Neither establishes physical presented-frame AC-20 performance.

Three.js

WebGL

made of triangles. GLB is a compact binary container for glTF geometry/materials. None of these
technologies guarantees anatomical accuracy.
Renderer and asset identity
N05 loads three immutable licensed GLBs for body, skeleton and organs. Five semantic meshes
represent body, skeleton, heart and two lungs. The source lineage is 
BodyParts3D 4.3 / FMA 3.0
, 326
original source elements, credited to the Database Center for Life Science under 
CC BY-SA 2.1 Japan
.
The generic reference body is not a crew scan. Heart coverage is incomplete and independent fidelity

The waveform engineering path
The current N08 parser accepts its own explicitly synthetic ASTRAWV1 binary and ASTRACSVv1 CSV

14 · N11: anomaly evaluation and rejection
An 
anomaly
 is an observation unusual relative to a reference. Unusual does not mean disease. N02
uses fixed review rules; N11 compares advanced candidate methods in a separate research/shadow
evaluation. A candidate never earns operational authority just because its code runs.
Three kinds of research logic
Method
Simple explanation / implementation role
Robust personal reference
Describe a person’s baseline and scale before scoring changes; source quality
and eligible history matter.
EWMA
Exponentially weighted moving average gives more weight to recent values while
remembering older ones. It can emphasize sustained drift.
Isolation Forest
Build random partition trees. A point isolated after fewer splits may be more
unusual than points requiring many splits. It is not a supervised medical-diagnosis
model.
How Isolation Forest works
Imagine repeatedly splitting a scatterplot with randomly chosen features and cut points. A lone remote
point is often separated quickly. A dense cluster usually takes more cuts. The algorithm averages path
lengths and converts them to a rarity score. Its usefulness depends on feature scaling, population, quality,
training distribution and a defensible evaluation design.
ASTRA implements candidate research logic in repository JavaScript, including reference fitting, feature
extraction, EWMA and forest scoring. This is not evidence of a hidden online AI service or a currently
deployed scikit-learn detector. Research job/result/event records preserve policies and outcomes so
failed results are not erased.
The actual outcome matters more than the model name

Intervals and abstention
N12 forms empirical residual-based intervals using a calibration quantile aimed at nominal 90% coverage.

24 · Real-world value and future work
Space missions may face communication delays, limited bandwidth and periods without immediate
ground assistance. A local tool that preserves observations, shows quality, supports human review and
makes evidence available offline could be useful in that setting. The current prototype explores those
engineering needs; it does not prove suitability for an actual mission.
What the implemented prototype contributes
A reproducible synthetic scenario can demonstrate exactly how an observation becomes a persisted
review event, rather than an unexplained colored card.
Source and knowledge timestamps let replay distinguish an earlier event from information learned
later.
Crew-bound anatomy offers navigation into permitted data without pretending to localize disease.
Offline quotations, explicit abstention and separate model-promotion gates keep attribution distinct
from unsupported conclusions.
Durable transactions, idempotent commands and cold recovery make demonstrations inspectable
after interruption.
What must happen before real sensor or clinical use
Future work — not delivered by this PDF mission
Why it matters
Acquire approved authentic datasets and device interfaces
Define source rights, consent, calibration, units,
cadence, quality and clock behavior before
interpreting readings.
Independent expert/source/annotation review
Check anatomical fidelity, evidence applicability,
reference windows and question labels without the
developer impersonating a reviewer.
Prospective model evaluation and parity
Use independent data and reference
implementations; do not promote from questions or
scenarios used during tuning.
Hardware and operational qualification
Measure designated physical display performance,
resource bounds, secure identities and failure
behavior in the intended environment.
Clinical and human-factors evaluation
Test benefits, harms, workflow comprehension,
false alarms, privacy and medical oversight.
Release and mission governance
Obtain explicit deployment approval, appropriate
safety/regulatory assessment and operating
procedures.
Other possible settings
Remote field stations and ships suggest analogous research directions, not demonstrated deployments.
Human oversight remains essential for sensor checks, alert review, scientific applicability and any clinical
action.
Recommended next milestone:
 close the independently owned validation gates in order—
especially physical AC-20, anatomy fidelity and source/review eligibility—before expanding
operational AI. That is a proposed roadmap, not authorization to begin it now.

Frontend.
 The browser interface a user sees and
controls.
Backend.
 The local service that validates, reads,
computes and stores results.
API.
 An agreed interface for requests between
programs.
Database.
 An organized store of records with defined
read/write rules.
SQLite.
 An embedded database engine using local
files.
JSON.
 A text format for objects, lists and values.
REST.
 A resource-oriented style of HTTP API design.
HTTP.
 The request/response protocol used by the
browser and server.
Localhost.
 Your own machine, commonly addressed
as 127.0.0.1.
Node.js.
 The runtime executing ASTRA’s server-side
JavaScript.
JavaScript.
 The programming language used across
ASTRA’s main implementation.
Synthetic data.
 Intentionally generated data, not
measurements from the represented person.
Real-world data.
 Observations collected from an
actual source/population, subject to rights and context.
Telemetry.
 Time-stamped measurements transmitted
or recorded for monitoring.
Sensor.
 A physical device measuring a property of the
world.
Waveform.
 A sequence of signal samples across time.
Sampling rate.
 Samples recorded per second,
measured in hertz (Hz).
Simulation.
 Software generation of controlled
scenarios or observations.
Deterministic.
 Reproducible output for the same
inputs and state.
AI.
 A broad term for computational methods performing
intelligent-seeming tasks.
Machine learning.
 Methods that fit patterns from data

LLM.
 A large language model trained to
predict/generate text.
Qwen.
 The model family used in ASTRA’s local text-

Quantization.
 Reducing numerical weight precision to
save model resources.
Embeddings.
 Learned numerical representations of

Retrieval.
 Finding existing relevant items or text
passages.
RAG.
 Retrieval-augmented generation: give retrieved

Hallucination.
 A fluent generated statement not

Anomaly.
 An unusual pattern relative to a chosen

Forecasting.
 Estimating later values from earlier

Linear regression.
 Fitting a line relating input

 Random partition trees scoring how

 A system coordinating bounded actions or tools

 Invoking a defined external function with

 A JavaScript library for constructing and

 A browser graphics interface for accelerated

 A surface described by vertices and triangles.

 A binary glTF container for 3D geometry/material

 The origin, version and transformation

 A content fingerprint useful for detecting

 Independent evidence that a

 Explicitly withholding an answer when
