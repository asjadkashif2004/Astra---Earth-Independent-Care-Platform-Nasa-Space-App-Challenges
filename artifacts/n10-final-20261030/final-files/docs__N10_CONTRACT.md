Under activated DE-N10-SYNTHETIC-01, the owner approves all S1/S2/S3/C1/C2/E1/E2/R1/A1/V1 groups. Formal N10 remains In Progress until original closure gates are legitimately satisfied. No operational or N16 source/model permission follows.

## Data and privacy

One append-only schema4 N10 ledger reuses Store's existing transaction/audit infrastructure. Versioned records bind crew, kind, stable ID, revision, actor, source time, server-owned mission knowledge time, separate host submission timestamp, explicit source/quality, content digest and previous crew-chain digest. Corrections append with expected revision; same request ID and identical payload recover the committed record, conflicting reuse rejects. Reads verify the ledger and do not initialize, migrate, checkpoint or persist computed summaries.

Kinds: stage, schedule, sleep_status, consent, checkin, exercise_plan, exercise, movement. IDs/fields/UTC timestamps/enums/bounds are validated. Source is authored_synthetic or browser_task; browser task is separate from synthetic sensors and authored task fixtures. No records are generated automatically on read. Sleep actuals reuse the completed-sleep ledger unchanged. An explicit authored sleep_status may declare missed/partial/unknown; missed conflicts with an existing canonical session, and partial must bind that session and withholds full-duration accounting. Absence alone never establishes a missed session.

Stage names preserve the existing EDF annotation labels exactly: Sleep stage W,1,2,3,4,R,?, Movement time, Sleep stage M (each numbered/lettered label retains the full Sleep stage prefix). The unknown/movement labels never become inferred sleep. Daily aggregation clips supplied intervals to UTC day boundaries; overlaps invalidate totals instead of double counting. Gaps, missing/poor-quality observations and UNKNOWN labels reduce coverage. Staging is explicitly authored synthetic, not inferred from a duration.

Schedule records bind start/end, effective UTC date range, status and reference duration equal to their declared interval. Comparisons use the selected dated schedule and canonical completed session. Formula: planned hours minus observed hours; positive part is a descriptive shortfall. Cumulative shortfall is available only when every day in the requested bounded window has an eligible plan and canonical actual. No clinical sleep need/impairment threshold or N02 rule is introduced.

N10 has an explicit role boundary separate from generic telemetry read. Astronaut is self-scoped; Demo Administrator authors synthetic records. Mission Control/Flight Surgeon may read non-private N10 data. Private mood/fatigue/trials require the subject's current per-actor grant and optional sharing permission for reviewers; demo admin sees only own private records. Viewer/Researcher/System Administrator are denied N10 records. Consent is versioned, with separate mood/fatigue/task/share_review flags. Decline/withdrawal prevents optional collection and hides raw private history even when replay asks for an earlier date. New grants create a new eligibility epoch. Skip/cancel stores no optional response or invented healthy value.

Existing legacy check-in semantics are preserved for old callers before any N10 consent state; legacy records are explicitly excluded from N10 task references. Once N10 consent exists for that actor/crew, withdrawal/decline or disallowed fields cannot be bypassed through the legacy endpoint.

## References, exercise and replay

Task reference policy personal-reference-v1 requires at least three prior eligible completed five-trial records for the same crew, actor, task protocol, declared device/profile, source kind/identity and consent epoch. Each trial preserves100–3000ms validation; browser timing is approximate. A non-secret random local browser-profile ID replaces user-agent-based identity; it is not authenticated hardware. Blocked storage produces a new ephemeral ID, not a guessed shared device. No private task responses are cached. The latest eligible task is compared with the median of prior per-session means, never itself/future records, population norms or another crew. Reference version hashes eligible IDs/revisions and policy; no read-side baseline writes. Insufficient history is UNKNOWN.

Exercise plans declare a denominator; cancellation removes that plan from eligibility. A performed/partial/missed record refers to the exact plan revision, category and units. A missing/cancelled/unverified result leaves adherence UNKNOWN; it is never confirmed nonadherence. Only fully resolved eligible plans produce completed/eligible percentage. Workload uses explicitly declared W/kg/arbitrary_unit without conversion. Movement requires a supplied source interval, steps and coverage; absent/overlapping/unverified evidence is UNKNOWN. No clinical interpretation follows.

Replay applies source_at<=cutoff AND known_at<=cutoff before latest-revision selection. Future plans may be displayed as plans, never observations. Optional privacy uses current consent as an additional authorization gate. Day histories are UTC, with explicit mission/source/knowledge clocks; Earth view does not fetch onboard N10 data. Historical reads never mutate state.
